# 开放与开源计划

## 开源范围

- 7 个 Agent Identity 模板与 17 个 Skill（标准 Schema + 纯 Python 实现）
- MCP 等价 Mock Server（订单/工单/支付/物流）
- Golden/Badcase 评估数据集与评估脚本
- 全链路 Trace/Log/Metrics 样例与回放脚本
- AgentTeams 部署配置（`agentteams/`）与 Docker Compose 一键演示

## 协议与合规

- 代码采用 MIT License；文档采用 CC BY 4.0。
- 必选依赖：Python 3.8+（默认零外部依赖，规则引擎兜底）。
- 可选依赖：OpenAI 兼容 SDK（真实 LLM）；复赛将接入 AgentTeams 与通义千问。
- 商业 API 按调用量计费，方案提供规则引擎兜底与自部署替代。
- 初赛数据全部为合成 Mock 数据，无真实个人信息；接入企业数据前需授权并脱敏。

## 阿里云官方用云 Skills

方案规划接入阿里云官方用云 Skills 作为基础设施能力层（云资源查询、配置治理等）；客服业务能力由自定义 Skill 沉淀。官方 Skills 使用托管凭据与最小权限鉴权，调用统一进入 Trace/Log/Metrics，避免重复构建基础能力。

## 长期维护计划

- 版本化发布 Skill 与 MCP 适配器；知识库更新走人工审核。
- 维护评估数据集与回归基线，持续优化意图准确率、工具成功率与满意度。
- 社区接受 Issue/PR，维护 README、示例与兼容性说明。
