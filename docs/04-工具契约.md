# MCP 工具接入契约

初赛提供 MCP 等价契约（HTTP + JSON-RPC）与 Mock Server；复赛以同一 Schema 接入真实系统。所有写操作遵循统一约定：鉴权、幂等、错误码、审计事件。

## 通用契约

- **协议**：`POST /mcp`，`tools/list` / `tools/call`
- **鉴权**：服务端 AK/SK 或 OAuth2.0 client_credentials；Agent 按角色最小权限
- **幂等**：写操作必须携带 `idempotency_key`，重复调用返回同一结果
- **错误码**：`INVALID_ARGUMENT`、`NOT_FOUND`、`PERMISSION_DENIED`、`RATE_LIMITED`、`CONFLICT`、`INTERNAL`
- **审计**：每次调用生成审计事件（调用方、参数摘要、结果、TraceId）
- **回滚**：退款等写操作返回回滚点，支持 `rollback_refund`

## 1. order_system 订单系统

操作：`query_order`（L0）、`update_address`（L1）、`process_refund`（L2）、`rollback_refund`（L2）

```json
{
  "name": "order_system.process_refund",
  "inputSchema": {
    "type": "object",
    "required": ["order_id", "reason", "approval_id", "idempotency_key"],
    "properties": {
      "order_id": {"type": "string"},
      "reason": {"type": "string"},
      "amount": {"type": "number"},
      "approval_id": {"type": "string"},
      "idempotency_key": {"type": "string"}
    }
  }
}
```

## 2. ticket_system 工单系统

```json
    "type": "object",

    "properties": {
      "problem_desc": {"type": "string"},
```

```json
  }
}
```

## 迁移到真实系统

- Mock 与真实系统共用同一 Schema，仅替换 MCP Server 的 transport/backend。
- 真实接入增加：环境隔离、密钥轮换、限流熔断、数据源授权核验。
- 迁移成本集中在环境与权限配置，不重设计工具调用链。
