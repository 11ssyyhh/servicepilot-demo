# 评审演示脚本（5-8 分钟）

## 1. 开场 30 秒

一句话介绍：ServicePilot 是一套基于 AgentTeams Manager-Workers 架构的智能客服 Agent 基础设施，用 7 个职能 Agent 完成「进线、意图识别、RAG 检索、任务规划、工具执行、质量审核、效果验证、记忆沉淀」的自主闭环。

线上入口：

- 在线 Demo：<https://11ssyyhh.github.io/servicepilot-demo/>
- 人工审批台：<https://11ssyyhh.github.io/servicepilot-demo/approval.html>
- 证据目录：<https://11ssyyhh.github.io/servicepilot-demo/evidence/>
- 代码仓库：<https://github.com/11ssyyhh/servicepilot-demo>

## 2. 现场演示 3 分钟

按顺序跑 7 个场景，讲清三种闭环形态：

1. 订单查询：L0 只读，自动查询并回复，全程 Trace 留痕。
2. 退款审批通过：L2 高风险，演示审批通过后幂等执行退款，生成退款单号与回滚点。
3. 退款审批拒绝：L2 审批拒绝，自动转人工工单，回复中明确告知用户。
4. 修改地址：L1 自动执行，但因订单已发货执行失败，自动创建转人工工单。
5. 用户投诉：识别负面情绪与高紧急度，创建高优先级工单并安抚。
6. 退货咨询：RAG 知识库命中，低风险自动回复。
7. 未知问题：RAG 置信度低于阈值，自动转人工，避免机器人乱答。

命令：

```bash
python main.py 1
```

## 3. 人工审批续跑 1 分钟

这是本项目与普通客服机器人的关键差异：人工决策后，Agent 团队会继续把闭环跑完。

```bash
# 终端 1：启动审批服务
python approval_server.py 8080

# 终端 2：运行演示，产生待审批退款（output/pending_approvals.json）
python main.py 1

# 浏览器打开 http://127.0.0.1:8080/approval.html
# 对退款申请点击「通过」

# 终端 3：读取审批决策并自动续跑
python resume_approval.py
```

讲解要点：审批只暂停风险动作，不中断会话；审批通过后 ToolExecutor 使用同一幂等键执行退款，QualityGuard、Verifier、MemoryScribe 继续完成审核、验证与沉淀，全程写入同一 trace_id。

## 5. 常见提问应答

- 为什么用 AgentTeams：赛道要求以 AgentTeams 为协同设计基点，本项目将 Manager-Workers、SharedState、Skill、MCP 契约逐项映射，见 docs/08。
- 如何保证高风险操作安全：L0-L3 分级、审批门禁、幂等键、回滚点、审计事件，四层机制共同兜底。
- 与真实平台如何衔接：初赛用 Mock 业务系统验证契约，agentteams/ 已提供 team.yaml 与 workers.yaml，复赛可平移至真实 AgentTeams 平台。
- 后续规划：接入真实业务 API、通义千问 LLM、扩充评估数据集、接入 AgentLoop 可观测看板。
