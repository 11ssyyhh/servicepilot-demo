# 作品简介（500 字内）

项目名称：ServicePilot——智能客服多 Agent 自主闭环系统

电商客服面临复杂问题单 Bot 无法解决、高风险操作依赖人工、处置过程不可追溯等痛点。本项目以 AgentTeams 的 Manager-Workers 架构为协同基点，构建 7 个职能 Agent：意图路由、知识检索、任务规划、工具执行、质量风控、效果验证、记忆沉淀，完成「进线 → 意图识别 → RAG 检索 → 任务规划 → 工具执行 → 质量审核 → 效果验证 → 记忆沉淀」全链路自主闭环。系统沉淀 15+ 可复用 Skill，覆盖诊断、知识、执行、治理、记忆五类能力；通过 MCP 等价契约对接订单、工单、支付、物流系统，所有写操作携带幂等键与回滚点，L0-L3 四级风险分级，L2 退款等高风险操作必须人工审批并全程审计。全链路 Trace/Log/Metrics 支持回放与回归评估，Golden/Badcase 数据集驱动持续优化。初赛已跑通订单查询、退款审批通过、退款审批拒绝、地址修改失败转人工、投诉高优工单 5 个场景闭环，26 项测试通过，评估通过率 100%。后续将开源 Skill 模板、MCP Mock Server 与评估数据集，并接入真实 AgentTeams 平台、业务系统 API 与可插拔 LLM，推动客服从人工经验走向可治理、可复用、可审计的 Agent Infra。
